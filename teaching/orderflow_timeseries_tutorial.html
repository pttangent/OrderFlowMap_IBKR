手机左右滑动

一根 Candle，旁边就是这一根自己的 Footprint

从左往右是时间。每一栏先看 Candle 有没有价格进展，再看同一根内部的 Sell@Bid / Buy@Ask / Delta。这样才能理解“交易过程”，而不是把整个窗口压成一张统计表。

青框 = 单根 POC；橙框 = diagonal imbalance。BID ABS / OFFER ABS 是流量与 Candle 结果背离的结构提示。

TIME → 每一栏 = 30 秒 bar；向右滑动就是之后发生的交易
读法顺序
1. Candle 有没有前进？
2. 哪一边主动成交？
3. POC / imbalance 在哪里？
4. 下一根有没有延续或失败？
Sell = Sell@Bid；Buy = Buy@Ask；Δ = Buy − Sell。没有 L2 时不把挂单热图伪造成真实深度。
